Before you run the installer

Windows will warn you once

The installer is not code-signed yet, so SmartScreen says “unknown publisher”. Click More info, then Run anyway. It installs for your user only; the app itself needs no administrator rights.

Check the file

Every release lists SHA-256 checksums in SHA256SUMS.txt. Compare with Get-FileHash .\DualForge-Setup-*.exe in PowerShell.

Quick start

  1. Install

    Run DualForge-Setup-<version>.exe and get past SmartScreen as above.

  2. Plug in over USB

    Connect the DualSense with a USB cable (Bluetooth is not supported yet) and open DualForge. Home should say “Connected · USB”.

  3. Install the drivers from Health

    Open Health. Click Install ViGEmBus (required: without it games cannot see the virtual controller) and accept the Windows prompt. Install HidHide is recommended: reboot if it asks, then turn on Hide the DualSense from games in Settings so games never see two pads.

  4. Match your controller

    On a stock DualSense: on the Triggers page turn Digital (mouse-click) trigger off for Left and Right, turn on This controller has rumble motors in Settings, and calibrate both sticks once on the Sticks page.

  5. Turn on updates

    In Settings → Updates, turn on Check for updates. When a new version is out you click Download, then Install & restart; nothing installs without you.

You need

Windows
10 or 11, 64-bit
Controller
PS5 DualSense on a USB cable
Driver
ViGEmBus, installed from the Health page in one click
Optional
HidHide, so games see only the virtual controller

Something not working?

Open Health in the app first: it shows what is wrong and offers a repair. If that does not fix it, click Export diagnostics bundle and attach the zip to an issue, with the error code from the app's footer.
